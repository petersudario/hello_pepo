# Pepo's MemoBox (Meet Pepo)

This app is **about my own memories**—moments from my life told as chapters. It is built as an interactive memoir for iOS: you swipe through stories, hear narration, preview 3D objects that symbolise each memory, and unlock AR scenes tied to a printed marker.

## Description

**Pepo's MemoBox** is an **iOS 17+** SwiftUI package app built with Xcode. Each chapter is a **personal memory**: short texts I wrote, voice clips, and a **USDZ** model that stands for that moment (games, films, people, objects from my life—not a generic catalogue). **ARKit** image tracking appears where a chapter unlocks the AR “memory” scene.

The whole experience is autobiographical: progression mirrors how I chose to tell these stories, not a fictional game world.

Third-party models and sounds are credited in **`memobox.swiftpm/links_credits.txt`**.

Icons and raster assets under **`memobox.swiftpm/Sources/Materials/Assets.xcassets`** (and related materials) were produced by me in Figma / tooling—please credit if you reuse them.

## Features

- Memoir-style chapters: unlock and revisit memories in order  
- Story screens with typewriter-style text and my recorded narration  
- Vaporwave-styled chrome  
- 3D model preview—each model echoes a real memory, not random props  
- AR scene anchored to a printable marker (`Materials/Images/marker.png`)

## Requirements

- **Xcode** 16 or later (recommended)  
- **iOS** 17.0 or later  
- **Swift** 6  
- Physical device with camera for AR (simulator is limited)

## Project layout

| Path | Purpose |
|------|---------|
| `memobox.swiftpm/` | Swift package application (main target) |
| `memobox.swiftpm/Sources/` | Swift sources (`Views`, `ViewModels`, `Materials`, …) |
| `memobox.swiftpm/Package.swift` | Package manifest (generated by Swift Playgrounds / Xcode) |
| `spec/` | OpenSpec capability docs (chapter story experience, etc.) |

CLI builds use the workspace inside the package:  
`memobox.swiftpm/.swiftpm/xcode/package.xcworkspace` with scheme **Pepo's MemoBox**. Plain `swift build` does not apply (manifest uses `AppleProductTypes`).

## Installation

1. Clone the repository:
   ```bash
   git clone git@github.com:petersudario/hello_pepo.git
   cd hello_pepo
   ```
2. Open the Swift package app folder in Xcode:
   ```bash
   open memobox.swiftpm
   ```
   Alternatively open the workspace:
   ```bash
   open memobox.swiftpm/.swiftpm/xcode/package.xcworkspace
   ```
3. Select scheme **Pepo's MemoBox**, choose an **iPhone or iPad** destination with iOS 17+, then **Run**.

4. For AR: print **`memobox.swiftpm/Sources/Materials/Images/marker.png`** (or the asset referenced by your build) and point the camera at it when the AR flow asks.

> **Note:** AR behaves best on a **real device**.
